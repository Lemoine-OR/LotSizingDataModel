# LotSizingDataModel Doxygen documentation pack

This pack is designed to be merged at the root of the `Lemoine-OR/LotSizingDataModel` repository.

It contains:
- one shared, curated `Doxyfile.common`;
- one project-specific `Doxyfile` for each of the 13 Visual Studio projects;
- one main page per project;
- a two-pass documentation builder that generates tag files first, then fully cross-linked HTML;
- a GitHub Pages documentation portal;
- a GitHub Actions workflow pinned to the official Doxygen 1.17.0 Windows x64 archive with SHA-256 verification;
- optimized project graphics and a multi-resolution DLL/package icon;
- a compatibility `Doxyfile-LotSizingDataModel.Core` at repository root.

The generated site is written to `Documentation/site` and is published by GitHub Pages.
