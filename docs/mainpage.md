\# LotSizingDataModel



\*\*A modular C# framework for modeling, importing, solving and validating lot-sizing problems.\*\*



LotSizingDataModel provides a reusable object model and a set of supporting libraries for the representation and solution of lot-sizing problems.



\## Main components



\- \*\*LotSizingDataModel.Core\*\*  

&#x20; Core domain model and common abstractions.



\- \*\*LotSizingDataModel.Instance\*\*  

&#x20; Lot-sizing instances, descriptors and problem characterization.



\- \*\*LotSizingDataModel.Solution\*\*  

&#x20; Representation of production, inventory and setup decisions.



\- \*\*LotSizingDataModel.Import\*\*  

&#x20; Import and conversion utilities for external benchmark formats.



\- \*\*LotSizingDataModel.Solver\*\*  

&#x20; Solver-independent modeling and execution infrastructure.



\- \*\*LotSizingDataModel.Solver.Cplex\*\*  

&#x20; IBM ILOG CPLEX adapter.



\- \*\*LotSizingDataModel.Solver.Console\*\*  

&#x20; Command-line solver application.



\- \*\*LotSizingDataModel.Checker\*\*  

&#x20; Generic solution verification framework.
