# LotSizingDataModel 1.2.0 — Stable Release Candidate

## Scope

Version 1.2.0 is the first stable promotion of the NextGen universal-model
roadmap after alpha.44 hardening.

The stable-promotion candidate adds no scientific functionality.

## Stable contracts

The following are promoted to stable 1.2.x contracts:

- critical public consumer anchors in `PUBLIC-API-CONTRACT.json`;
- protected instance/solution XML roots in `XML-COMPATIBILITY-CONTRACT.json`;
- downstream dependency direction;
- absence of presentation-framework dependencies from foundational assemblies.

## Explicit non-claims

The stable release does not claim support for every scientifically imaginable
extension.

Open capabilities are recorded in `governance/STABLE-OPEN-GAPS.json`.

In particular, 1.2.0 does not claim:

- explicit machine-level quantity assignment across parallel machines;
- explicit reverse physical transport routing;
- endogenous generation of product returns;
- unproven default Bitran-Yanasse inverse mappings;
- automatic support for features explicitly classified CatalogOnly or
  KnownUnsupported.

These gaps are deliberate scope boundaries, not hidden failures.

## Publication

This candidate validates the stable version locally but does not push, tag or
create a GitHub Release.

Publication remains a separate explicitly authorized step.
