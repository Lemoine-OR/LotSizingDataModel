# Historical Classification Capability

The scientific engine reports what it can safely do with historical schemes;
it does not manufacture historical labels.

## Bitran-Yanasse

The descriptor can be assessed for the classical single-item capacitated
domain.

A complete Bitran-Yanasse code still requires explicit temporal profiles for:

- setup cost;
- holding cost;
- production cost;
- capacity.

The engine therefore reports an applicability/capability state, not an
invented historical code.

## Wolsey 2002

Historical-to-universal mapping is implemented.

However, inferring a unique historical `PROB-CAP-VAR` source code from an
arbitrary modern descriptor is a different operation and is not claimed by
alpha.16.

The engine reports `MappingSupportedOnly`.

## Principle

`CanMapDeclaredClassification != CanDetectCompleteHistoricalCode`.

This distinction prevents the existence of a mapper from being mistaken for
an automatic historical classifier.
