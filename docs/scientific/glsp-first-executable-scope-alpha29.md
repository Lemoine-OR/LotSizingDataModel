# GLSP First Executable Scope — alpha.29

Supported: canonical single-resource GLSP macro/micro structure, variable-length micro-periods, exact sequence across macro boundaries, sequence-dependent changeover times/costs, canonical setup carry-over, production lead times through the aggregate-production bridge, and compatible existing inventory/network semantics.

Explicitly unsupported for this first executable scope: initial setup state; forbidden setup carry-over; generic per-item SetupTime and FixedSetupCost; start-up cost/time; minimum/maximum/multiple lot-size constraints; additional production capacity; financial operating budgets; multiobjective execution; multi-site/parallel scheduling; MaximumSetupCount; MaximumProducedItemCount; GroupingConstraint.

All unsupported items remain planned extensions and must be integrated without changing their existing semantics.
