# Problem-Class Support after alpha.27

## Executable

- SI-ULS
- SI-CLSP
- MI-ULS
- MI-CLSP
- UMLSP
- MLCLSP
- DLSP
- CSLP
- PLSP

## Classifiable

No canonical class currently remains in this intermediate state.

## CatalogOnly

- GLSP

`Classifiable` remains a valid support state in the API because future problem
families may again be scientifically recognizable before their formulations
become executable.

GLSP is deliberately not promoted by analogy: its macro/micro-period and
sequencing semantics require the next dedicated modeling milestone.
